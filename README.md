# Velária — Wiki

Wiki do servidor MMORPG Velária (Minecraft 1.21.1 + NeoForge).

- As páginas ficam em `docs/` (Markdown + imagens).
- `gen_wiki.py` gera as páginas a partir dos dados do modpack.
- Cada push na branch `main` publica o site no GitHub Pages (`.github/workflows/pages.yml`).

Para ver no seu PC: `pip install mkdocs-material` e depois `mkdocs serve`.
